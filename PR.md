## Разбор заявки

API проверяет входной JSON и текст до обращения к имитатору. После ответа проверяет тему по списку допустимых значений и удаляет крайние пробелы из черновика. При таймауте в 300 мс, ошибке или некорректном ответе API возвращает manual_review с пустыми темой и черновиком. Страница сохраняет текст заявки, очищает старый результат и предлагает ручной разбор. Поздний ответ на прошлый запрос игнорируется.

## Проверка

Использован OpenAI Codex для подготовки реализации и автотестов. Автоматически проверены три допустимые темы, ошибки ввода, пять режимов сбоя, переход к ручному разбору, сетевой сбой и обратный порядок ответов. Проверки обработчиков страницы используют подмену DOM и сети.

Node.js 20 или новее. Запуск приложения — node server.mjs, адрес — http://127.0.0.1:3000. Запуск тестов — node --test.

## Польза

Менеджер может сразу продолжить работу вручную, не рискуя отправить предыдущий черновик. Эффект можно измерять временем подготовки ответа и количеством показов чужого черновика.

## Что я проверил самостоятельно

На Windows запустил node --test. Прошли все 19 тестов.
В браузере отправил заявку «Сколько стоит доставка?» и получил тему и черновик.
Затем ввёл [timeout]. Появилась подсказка о ручном разборе, текст заявки остался в поле, а предыдущий черновик исчез.
